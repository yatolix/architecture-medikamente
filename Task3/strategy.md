## Реестр программных и аппаратных средств защиты данных

**Программные средства (типовые решения):**

1. **Шифрование:**
   * BitLocker — дисковое шифрование.
   * PostgreSQL pgcrypto — TDE/полевое шифрование.
   * HashiCorp Vault — управление ключами и секретами, Secure Vault.
2. **Маскирование и обезличивание:**
   * В De-Identification Service можно использовать встроенные возможности и расширения Spring Boot.
3. **Контроль доступа и идентификация:**
   * Keycloak, Active Directory — IAM.
   * Casbin — PBAC Engine.
4. **Предотвращение утечек (DLP):**
   * Symantec DLP
5. **Мониторинг и аудит:**
   * Elastic Security — открытая SIEM.
6. **Классификация данных:**
   * OpenDLP — сканирование контента.
7. **Сетевая защита:**
   * VPN WireGuard, OpenVPN.
8. **Безопасность приложений:**
   * Статические анализаторы (SAST): SonarQube, Checkmarx.
   * Динамические анализаторы OWASP ZAP.
9. **Резервное копирование и восстановление:**
    * Veeam Backup & Replication, CommVault.
    * Обязательное шифрование резервных копий.

**Аппаратные средства (HSM/токены):**

* Hardware Security Module (HSM): nCipher, Thales, Utimaco — для хранения мастер-ключей шифрования.
* Рутокен, JaCarta — для хранения ключей ЭП сотрудников.
* Защищённые серверы с TPM 2.0.
